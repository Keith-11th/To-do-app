#TO-DO LIST

A simple to-do list built with plain HTML, CSS, and JavaScript with no libraries or frameworks.

## Features

- Add tasks with the button or the Enter key
- Click a task to mark it as done
- Delete tasks you no longer need
- Tasks are saved in the browser, so they are still there after a refresh

## How to run

1. Download or clone this repository
2. Open `index.html` in your browser

## What I practiced

- Selecting elements and handling events in the DOM
- Creating and removing elements with JavaScript
- Storing data in an array of objects
- Saving and loading with localStorage
